Three small steps.

  1. Choose a paletteCopy its import from the card above.
  2. Open JellyfinGo to Dashboard → General → Custom CSS code.
  3. Paste and saveRefresh Jellyfin Web to apply the theme.

Use Jellyfin's built-in Dark theme for every variant except Latte, which works best over the built-in Light theme. Jellyfin 10.11 intentionally does not load server custom CSS inside the administration dashboard.

Real portrait episode art.

The Jellyfin 12 plugin samples each episode and stores a Witzi-styled 2:3 Primary poster with randomized frame borders beside the video.

Why inject JavaScript? Custom CSS cannot move Jellyfin's live detail elements, replace episode image requests, or coordinate cached backdrop transitions. The separate JavaScript Injector plugin targets Jellyfin 10.11, so Witzi Episode Posters installs its matching helper directly for Jellyfin 12 when the server starts.

Built for Jellyfin ABI 12.0.0.0 / .NET 10. Jellyfin needs write permission to each media folder and Jellyfin Web's index.html. Plugin 0.1.14.0 installs persistent Witzi Primary artwork, writes diagnostics to witzi-episode-posters.log, and caps poster generation at four concurrent episode workers to avoid memory and process-thread exhaustion. Poster frame decoding uses an available GPU when FFmpeg supports it and falls back to software otherwise. Download the manual plugin ZIP.
