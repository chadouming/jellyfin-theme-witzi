Witzi theme

Writes the compiled theme into index.html so it is in place before the first paint. Jellyfin applies the Custom CSS field only after the branding request resolves, so a theme pasted there shows stock Jellyfin colours and landscape home rows first, then snaps to Witzi. Turn this off to go back to Custom CSS delivery.
Anything still in the Custom CSS field loads after this one and keeps overriding it.
